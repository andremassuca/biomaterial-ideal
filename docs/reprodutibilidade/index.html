    Reprodutibilidade¶

    Todo o processo está implementado em Python, com testes automáticos para cada função. Os resultados regeneram-se a partir dos CSV de data/.

    Como reproduzir¶

    git clone https://github.com/andremassuca/biomaterial-ideal.git
cd biomaterial-ideal
python -m venv .venv
# Windows: .venv\Scripts\activate   Linux e macOS: source .venv/bin/activate
pip install -e ".[dev]"
pytest -q
python scripts/run_all.py

    scripts/run_all.py corre todos os casos e cenários, o Monte Carlo e a robustez, e grava os resultados em results/. Outros scripts: scripts/mc_triangular.py (sensibilidade do Monte Carlo à distribuição), scripts/listar_por_verificar.py (valores por verificar), scripts/figuras.py (figuras) e scripts/exportar_xlsx.py (folha de cálculo gerada a partir dos CSV).

    Semente e iterações¶

    • Monte Carlo das propriedades e dos pesos: 10 000 iterações, semente 42.
    • Repartições de Dirichlet da dupla contagem: 10 000, α = 1, semente 42.
    • Com 10 000 iterações, o erro-padrão de simulação de cada percentagem é no máximo 0,5 pontos percentuais.
    • O número de iterações é configurável (as funções de src/biomat_mcdm/ aceitam-no como argumento), o que permite correr versões rápidas na aplicação.

    Modelos para impressão 3D¶

    python scripts/impressao3d.py (com pip install -e ".[impressao]") gera os STL da haste femoral (Corail tamanho 8, 1:1) e do scaffold de filamentos 0/90 (10:1) em design/impressao3d/, verifica que as malhas são fechadas e grava as medidas. Instruções de impressão no design/impressao3d/LEIA-ME.md.
